# 아트 테마: 아기자기(cozy)

공공 데이터로 만든 지형·건물·도로의 **모양은 그대로** 둔다. 색감·재질·조명만 아기자기한 미니어처 디오라마 풍으로 바꾼다. 결정 기록은 `docs/decisions.md` D-014에 있다.

## 원칙
- 텍스처는 생성형 이미지 모델로 만든다. MonoGPT 라우터(OpenAI 호환, `.env`의 `MONOGPT_API_KEY`·`MONOGPT_BASE_URL`)의 최상위 이미지 모델을 쓴다. 후보를 비교해 고르고 `art/themes/cozy.yaml`에 적는다. 지금은 `gpt-image-2.6-sunburst`, 품질 high다. 다른 키나 제공처는 쓰지 않는다.
- 생성은 유료지만 사용자 지시로 크레딧을 제한하지 않는다. 품질은 high로 한다. 같은 프롬프트는 캐시를 다시 쓰고, 호출 수와 모델은 `art_manifest.json`에 남긴다.
- 지도·로드뷰·실사진을 참조 이미지로 넣지 않는다. 텍스처는 프롬프트로만 만든 일반 소재다(특정 건물·장소 재현 아님).
- 모양(기하)은 바꾸지 않는다. 존재하지 않는 건물이나 나무를 지어내 배치하지 않는다.

## 에셋 계약 (생성 도구 → Unity)

모든 파일은 `unity/JourneyOn/Assets/Art/Cozy/`에 둔다. 형식은 JPG(품질 92 안팎)이고, 모두 사방으로 이음매 없이 반복되는 텍스처다.

- 원본 생성 이미지(`art/raw/`)는 Git에 넣지 않는다. 후처리된 위 파일만 넣는다.

## Unity 테마 (cozy)
- **색:** 파스텔이지만 탁하지 않게 한다. 건물마다 지붕과 벽에 정해진 팔레트 안에서 살짝 다른 색을 준다. 색은 건물 id 해시로 정하므로 매번 같다.
- **조명:** 따뜻한 햇빛, 밝은 그늘(그림자 세기 낮춤), 파스텔 하늘·안개.
- **후처리(URP Volume):** 톤매핑, 채도·따뜻함 조금, 약한 블룸, SSAO(미니어처 입체감).
- **틸트시프트:** 조감 스크린샷·시연 영상에만 얕은 피사계 심도를 쓴다. 플레이 화면에는 쓰지 않는다.
- **수면:** 밝은 청록, 부드러운 반사.
- **원경 스커트:** 새 잔디 색조에 맞춘다.
