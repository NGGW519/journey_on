# 원천 데이터 확보 절차 (1단계: 달전리 북한강 수변)

조사일: 2026-11-17. 공개 웹 페이지만 조회했다(로그인·다운로드 안 함). 아래 "확인됨"은 출처 URL이 있는 사실이고, "추측"·"확인 필요"는 직접 화면에서 확인해야 한다. 국토정보플랫폼·브이월드 화면은 JavaScript로 그려져 메뉴 이름이 바뀌었을 수 있다.

1단계 범위(WGS84): 127.500–127.545 E, 37.778–37.830 N (자라섬·남이섬 선착장 + 남이섬 원경). 남이섬은 춘천시라 가평읍 행정경계 밖이므로, 행정경계로 자르지 말고 위 bounds 사각형으로 받는다.

## 가장 먼저 할 일 3가지

1. **국토정보플랫폼(map.ngii.go.kr) 회원가입·로그인.** DEM, 정사영상, 수치지도(연속수치지형도) 다운로드가 모두 여기서 시작된다. 로그인 없이는 다운로드 불가. 가입 후 공지사항 "대용량 파일전송 S/W 제공"의 프로그램을 미리 설치해 두면 다운로드가 막히지 않는다(다운로드 시 자동 설치도 됨).
2. **브이월드(vworld.kr) 회원가입·로그인 후 오픈API 인증키 발급.** GIS건물통합정보 SHP 다운로드와 행정경계 WFS에 쓴다. 키는 `.env`에만 넣고 문서·로그에 쓰지 않는다.
3. **국토정보플랫폼에서 DEM 해상도부터 확인.** 전국 5m DEM이 "공개제한 공간정보(안심구역)" 목록에 올라 있어서(아래 1번 참조), 공개 다운로드되는 DEM이 5m가 아닐 수 있다. 받기 전에 화면에서 해상도 표기를 확인하고, 5m가 없으면 알려 달라(그때는 Copernicus 30m interim을 계속 쓰고 대안을 정한다).

## 기획서 '확인 필요 사항' 답

> 정사영상·DEM 다운로드에 승인이나 대기 시간이 있는지

| 항목 | 확인된 것 | 확인 못 한 것 |
| --- | --- | --- |
| DEM | 공공데이터포털 안내상 로그인 + 대용량 전송 S/W로 받는 무료 파일. "승인 대기"를 언급한 공식 페이지는 찾지 못했다. | 실제 승인·대기 여부는 **확인 필요**(신청서 제출 후 즉시 받는 방식으로 보이나 추측). 해상도 5m 공개 여부 **확인 필요**. |
| 정사영상 | 로그인 후 지역 검색 → 신청서 작성 → 다운로드(전송 S/W) 방식으로 안내된다. 도시지역 12cm, 일반지역 25cm, TIFF. 별도 승인 단계는 공식 페이지에서 확인 못 함. | 대기 시간 **확인 필요**. 2010년대 매뉴얼은 "주문결제 → 구매내역에서 7일 내 다운로드"로 서술하나 오래된 문서라 현재 방식과 다를 수 있고, 무료인지도 신청 화면에서 **확인 필요**. |
| 건물(브이월드) | 로그인 후 다운로드. 이용허락 제한 없음/출처표시, 무료. | 승인·대기 **확인 필요**. |

결론: 공식 자료에서 "승인 대기 N일"이라는 명시를 찾지 못했다. 첫 신청을 넣고 화면에 뜨는 상태("신청완료/승인대기" 등)를 알려 주면 이 표를 갱신한다. 정사영상이 늦어지면 기획서 대비책대로 단색 재질로 먼저 진행한다.

## 1. DEM — 국토지리정보원 수치표고모델(공개 DEM)

- **사이트**: https://map.ngii.go.kr (국토정보플랫폼). 공공데이터포털 안내 페이지: https://www.data.go.kr/data/15059920/fileData.do
- **메뉴 경로(출처 기준, 화면 확인 필요)**: 국토정보맵 > 간편지도 검색(또는 통합검색)에서 지역·영역·반경으로 지정 > 항목에서 **공개DEM** 선택 > 로그인 > 신청서·사용자 준수사항 체크 > 다운로드. (수치지도 메뉴가 "수치지도 받기 > 공간정보받기 > 간편지도 검색"으로 표기되는 사례도 있음 — lazytrees.com/1502.)
- **선택 범위**: 위 bounds를 덮는 영역을 지도에서 직접 지정(영역 지정이 안 되면 도엽 단위로 선택, 가장자리 여유로 한 도엽 더). 남이섬 원경까지 포함.
- **형식**: IMG(파일데이터). **좌표계는 공식 페이지에 명시 없음** → 받은 파일로 확인해 `--crs` 지정(`python -m pipeline inspect --path <파일>`). 국토정보플랫폼 자료는 보통 EPSG:5186 또는 5179 계열(추측).
- **해상도**: 공공데이터포털 페이지에는 명시 없음. 국토지리정보원이 1m·5m·10m DEM을 구축한다는 자료와, 2015년에 90m 공개 DEM을 낸 보도(아시아투데이, 뉴시스)가 있고, 공간정보 안심구역(https://www.datafreezone.or.kr/center_01.do) 목록에 **전국 5m DEM이 공개제한 공간정보**로 올라 있다. 즉 **공개DEM이 5m인지는 확인 필요(리스크)**.
- **필요 S/W**: 대용량 파일전송 S/W(공지사항 "대용량 파일전송 S/W 제공", 다운로드 시 자동 설치). 열람은 지리OneView 또는 QGIS.
- **저장 위치**: `data/raw/official/dem/` (압축 풀어서, 파일명 유지)
- **예상 대기·승인**: 확인 필요(위 표).
- **이용조건**: 공공데이터포털 표기 "이용허락범위 제한 없음", 무료.
- **출처 표시 문구(제안, 제공처 지정 문구는 확인 필요)**: `국토교통부 국토지리정보원, 수치표고모델(DEM)`
- **등록 명령 예시**:
```
.venv/Scripts/python -m pipeline register --layer dem --path data/raw/official/dem/<파일>.img --source "국토지리정보원 수치표고모델(공개 DEM), 국토정보플랫폼" --license "공공데이터포털: 이용허락범위 제한 없음(출처 표시 권장)" --date <기준일 확인 필요> [--crs EPSG:5186]
```
(기준일은 파일 메타·신청서 화면에서 확인. 모르면 받은 날짜를 쓰고 "기준일 확인 필요"를 DATA_SOURCES에 남긴다. `--crs` 옵션 유무는 `pipeline register --help`로 확인.)

## 2. 항공 정사영상 (+ 국토위성 0.5m 보조)

### 2-1. 항공 정사영상
- **사이트**: https://map.ngii.go.kr — 공공데이터포털 안내: https://www.data.go.kr/data/15059919/fileData.do
- **메뉴 경로**: 국토정보맵 > 통합지도검색/지도자료에서 "달전리" 검색 → 마커에서 **정사영상** 선택 → 로그인 → 신청서 작성 → 다운로드. 항공사진 메뉴 URL은 `/ms/map/Aerial.do`(ngii 메인 페이지 링크). 장바구니 → "온라인 신청하기" → "선택 다운로드" 방식으로 서술한 블로그도 있음(daum geoscience/1109, 구버전 가능성).
- **선택 범위**: 1단계 bounds를 덮는 도엽/영역. 남이섬 원경까지. 촬영 연도가 여러 개면 가장 최근 연도 우선(홍보물이므로 최신성).
- **해상도·형식**: 도시지역 12cm, 일반지역 25cm, TIFF(공공데이터포털). 2010년 이후 촬영분만 제공. GeoTIFF/도엽 단위인지, 좌표계는 **확인 필요**(파일로 확인).
- **용량**: 수십 GB까지 갈 수 있다. 가능하면 범위를 좁게 신청하고, 받은 뒤 bounds로 잘라 둔다.
- **저장 위치**: `data/raw/official/ortho/`
- **예상 대기·승인**: 확인 필요. 무료 여부도 신청 화면에서 확인(공공데이터포털 표기는 이용허락 제한 없음).
- **출처 표시 문구(제안)**: `국토교통부 국토지리정보원, 항공 정사영상`
- **등록 명령 예시**:
```
.venv/Scripts/python -m pipeline register --layer ortho --path data/raw/official/ortho/<파일>.tif --source "국토지리정보원 항공 정사영상, 국토정보플랫폼" --license "공공데이터포털: 이용허락범위 제한 없음(출처 표시 권장)" --date <촬영연도 확인 필요>
```

### 2-2. 국토위성 0.5m 영상(보조, 선택)
- 확인된 것: 국토위성센터(https://www.ngii.go.kr/nlsc/service/method) 안내상 위성정사영상·모자이크영상·ARD는 **국토정보플랫폼의 국토정보맵**에서 이용하고, 원본자료는 공공기관·지자체의 공문 신청, 국토위성지도는 Open-API 신청으로 이용한다.
- 확인 못 한 것: 0.5m 해상도 표기, 무료 여부, 개인 이용 조건·승인 절차, 출처 표시 기준 → **확인 필요**. 항공 정사영상을 못 받을 때만 검토한다.

## 3. GIS건물통합정보 (AL_D010) — 브이월드

- **사이트**: https://www.vworld.kr (데이터 다운로드, 데이터셋 dsId=18로 안내되는 페이지가 있음). 공공데이터포털 안내: https://www.data.go.kr/data/15083092/fileData.do
- **메뉴 경로(출처 기준, 화면 확인 필요)**: 브이월드 > 데이터 다운로드(공간정보 다운로드) > "GIS건물통합정보" 검색 > 구분 "전체데이터" > **경기도(시도코드 41)** 파일 선택 > 로그인 > 다운로드. 파일명은 `AL_<시도코드>_D010_<날짜>.zip` 형식(예: AL_31_D010_20220402, 울산).
- **주의**: 받는 단위는 시도 또는 전국이다(시군구 단위 파일이 있는지는 **확인 필요**; 과제 메모의 "시군구 단위"는 확인하지 못함). 경기도 전체는 클 수 있다. 가평군(시군구코드 41820, 추측 — 법정동코드 확인 필요)만 pipeline에서 필터링한다.
- **형식·좌표계**: SHP(면). 공공데이터포털은 SHP, 일부 자료는 EPSG:5186, 2022년 블로그는 EPSG:5174(Bessel)로 서술 → **자료마다 다름. 받은 .prj로 반드시 확인**하고 필요하면 `--crs` 지정. 인코딩은 UTF-8 지원 프로그램으로 풀라는 안내가 있음(CP949 가능성, 확인 필요).
- **필드**: 컬럼 정의서(엑셀)가 데이터 다운로드 페이지에 함께 제공된다. **A0..An 코드의 정확한 의미는 공개 웹에서 확인하지 못했다.** 부분 정보와 매핑 제안은 `_workspace/01_geodata-collector_report.md` 참조. 받자마자 컬럼 정의서와 .dbf 필드명으로 확정할 것.
- **WFS(브이월드 오픈API)**: 행정구역은 레이어명 `lt_c_ademd`(읍면동), `lt_c_adri`(리), WFS명 `lt_c_ademd_info`, `lt_c_adri_info`(공공데이터포털 15059008). **건물 WFS 레이어명은 확인하지 못했다**(확인 필요). 1단계는 SHP 다운로드를 우선한다.
- **API 인증키 발급(출처: 블로그·ESRI 자료, 화면 확인 필요)**: vworld.kr 가입·로그인 > 오픈API(개발자센터) > 인증키 발급 신청 > 활용 API(2D 데이터 API, WMS/WFS API) 선택, **서비스 URL(도메인)·활용 용도** 입력 > 신청. 즉시 발급이라는 자료와 메일 승인 후 활성이라는 자료가 엇갈림 → 확인 필요. 키는 등록한 URL(도메인)에서만 동작하며, 로컬 개발용은 별도 도메인(localhost 등) 등록이 필요할 수 있다(추측). 사용기간·갱신 조건 확인 필요. 데이터 API 호출 시 `domain` 파라미터를 요구한다.
- **저장 위치**: `data/raw/official/buildings/`
- **예상 대기·승인**: 확인 필요.
- **이용조건**: 공공데이터포털 "공공누리 제1유형(출처표시)", 무료. 데이터 한계 안내: 전국적으로 구축기관이 달라 참고용으로 활용(공공데이터포털).
- **출처 표시 문구(제안)**: `국토교통부, GIS건물통합정보(브이월드)`
- **등록 명령 예시**:
```
.venv/Scripts/python -m pipeline register --layer buildings --path data/raw/official/buildings/AL_41_D010_<날짜>.shp --source "국토교통부 GIS건물통합정보(AL_D010), 브이월드" --license "공공누리 제1유형(출처표시)" --date <파일 날짜> [--crs EPSG:5186]
```

## 4. 수치지도 연속 2.0 (도로·하천·철도)

- **사이트**: https://map.ngii.go.kr. 공공데이터포털: https://www.data.go.kr/data/15059721/fileData.do (연속수치지형도), https://www.data.go.kr/data/15059719/fileData.do (수치지도 V2.0)
- **메뉴 경로(출처 기준)**: 국토정보맵 > 통합지도검색에서 시도(경기도)·시군구(가평군) 선택, 또는 간편지도 검색 > 인덱스에서 도엽 확인 → 수치지도 목록에서 **연속수치지형도(SHP)** 선택 → 로그인 → 신청서·준수사항 → 다운로드 → 신청내역관리에서 받기. 영역 직접 지정도 가능("행정구역이나 사용자가 원하는 영역을 제약 없이 신청", 공공데이터포털).
- **선택 범위**: 1단계 bounds. 항목은 교통(도로), 수계(하천), 철도만 골라도 된다.
- **축척·형식**: 1:5,000(권장, 레이어명 `N3...`), 1:25,000(`N4...`); SHP 또는 NGI. 좌표계: 자료마다 EPSG:5186/5179로 서술 → **.prj로 확인**.
- **레이어 코드(확인된 것만)**: 파일명 규칙 `N<축척 3|4><형상 A면|L선|P점>_<대분류 1자 + 7자리>`. 대분류 A 교통, B 건물, C 시설, D 식생, E 수계, F 경계, G 지형, H 주기. 확인된 개별 코드는 `N3L_A0010000`(도로경계 선, 브이월드 데이터셋 vworld_open_30180)과 `A0010000` 도로경계, `A0020000` 도로중심선 정도다(Search 요약 기준). **하천경계·실폭하천·철도의 정확한 코드는 확인 못 함** → 받은 뒤 법령 별표 "수치지형도 지형지물 표준코드"(별표1)와 대조.
- **브이월드 대안(추측성 보조)**: 브이월드에도 연속수치지형도 레이어별 SHP(예: 도로경계 선, 라이선스 CC BY 표기)가 올라 있다(https://data.edmgr.kr/dataView.do?id=vworld_open_30180). 국토정보플랫폼 신청이 막히면 같은 브이월드 계정으로 레이어별로 받는 길이 있다. 라이선스 표기(CC BY vs 공공누리)가 다르므로 받을 때 화면 표기를 그대로 기록.
- **저장 위치**: `data/raw/official/ndmap/`
- **이용조건**: 공공누리 제1유형(출처표시)(공공데이터포털 15059721).
- **출처 표시 문구(제안)**: `국토교통부 국토지리정보원, 연속수치지형도`
- **등록 명령 예시** (레이어 파일마다 한 번씩):
```
.venv/Scripts/python -m pipeline register --layer ndmap --path data/raw/official/ndmap/<N3L_A0010000>.shp --source "국토지리정보원 연속수치지형도 2.0(1:5,000) 도로경계, 국토정보플랫폼" --license "공공누리 제1유형(출처표시)" --date <기준일> [--crs EPSG:5186]
```

- **레이어(확인됨)**: 읍면동 `lt_c_ademd` / WFS `lt_c_ademd_info`, 리 `lt_c_adri` / WFS `lt_c_adri_info`. 시도 `lt_c_adsido`, 시군구 `lt_c_adsigg`.

## 받은 뒤 체크리스트 (모든 레이어 공통)

1. 파일을 `data/raw/official/<layer>/`에 넣고 압축은 풀어서, 원본 파일명은 바꾸지 않는다.
2. `python -m pipeline inspect --path <파일>`로 범위·좌표계·피처 수 확인(bounds를 덮는지, 0건이 아닌지).
3. `register` 실행 → 같은 레이어의 interim보다 우선 사용된다.
4. `docs/DATA_SOURCES.md`의 상태를 '확보'로, 기준일·좌표계·확인한 화면 표기 이용조건을 갱신.
5. 건물 SHP는 컬럼 정의서(엑셀)와 .dbf 필드명을 나란히 확인해 `_workspace/01_geodata-collector_report.md`의 필드 매핑을 확정.
